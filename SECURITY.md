
# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| Latest GitHub release | Yes |
| Current development branch | Best effort |
| Older releases | No |

We include security fixes in the next available release whenever possible.
If you are testing a local or modified build, please verify the issue against the latest code in this repository before reporting it.

## Reporting a vulnerability

Please do not open a public GitHub issue for suspected security vulnerabilities.

Instead, report it privately through [GitHub's private vulnerability reporting](https://github.com/nich227/DynamicNotch/security/advisories/new).

Please include:

- A clear description of the issue
- The affected version, release tag, or commit hash
- Your macOS version and Mac model, if relevant
- Steps to reproduce the issue or a proof of concept
- The possible impact you identified
- Any logs, screenshots, or crash details that help reproduce the problem

## What to expect

- An acknowledgment within 5 business days when possible
- Follow-up questions if more detail is needed
- Status updates during triage and remediation
- A fix or workaround in a future release when we confirm the issue

Please allow reasonable time for investigation and a coordinated fix before public disclosure.

If you are unsure whether something is security-related, report it anyway. We will triage it.
